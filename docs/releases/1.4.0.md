# YouEDA 1.4.0

## Download and install

Windows 10/11 x64. Install the .NET 10 Desktop Runtime, extract the entire
`YouEDA-1.4.0-win-x64.zip`, and run `YouEDA.exe`. Keep all adjacent files and folders.
This is an unsigned, framework-dependent desktop build, not an installer.
Verify the ZIP using the accompanying SHA-256 file.

## Included improvements

- One-click full CSV import with automatic family-based output, while retaining
  combined libraries. Deferred symbol choices allow automatic work to finish first.
- Shared concurrent CAD/model downloads, validated caches, model reuse, rate limiting,
  backoff, progress/speed indicators, and optional diagnostic logs.
- Centralized settings and removal of the unused standalone library-viewer tabs.
- JLCPCB/LCSC per-piece price snapshots with timestamp, currency, actual pricing tier
  and minimum-order information; pricing failures do not stop CAD import.
- 71 native common symbols with reviewed diode, transistor, ferrite, crystal,
  optoisolator, tantalum, switch and discrete-network selection rules.
- Automatic EasyEDA fallback preference for the reviewed regulator cases.
- KiCad wire-tip geometry, 50-mil-grid alignment, pad-enclosing courtyards, family
  footprint links, library tables and installed-location 3D model paths.
- MB10S/C2488 bridge and PSM712/C32677 network layout fixes with preserved passive
  pins, verified terminal roles, Small strokes and visible polarity/voltage labels.
- Build dependency patch uses serviced SDK SourceLink instead of the older explicit
  package that pulled in Microsoft.Build.Tasks.Git 8.0.0 (GHSA-23fw-v26w-5fgq).

## Validation and limitations

The pre-release acceptance dataset contains 351 components. All 351 exported symbols
passed the connection-grid check; the seven MB10S/PSM712 connections were verified in
an actual KiCad netlist. The other 349 symbols and all 351 footprint geometries,
courtyards and model poses were unchanged by the final network correction.

Regenerate libraries to receive the corrections; existing exports are not migrated.
Validate electrical mappings and physical geometry against manufacturer datasheets
before production. Automatic classification is not electrical certification. Some
source 3D placement issues still need review; models are not blindly recentered.
KiCad library/model paths are absolute: relink or regenerate after moving a library.
Prices are supplier snapshots, not binding assembly quotes. New Altium GUI acceptance
was not performed for this release. The agent-facing CLI remains experimental and is
not included as a supported release tool.
